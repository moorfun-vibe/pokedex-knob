Pokedex Knob Installer
======================
Voll-Anleitung: siehe die README.md im Repo / auf der Releases-Seite.

Kurz:
  1) Knob per USB-C anstecken (Datenkabel!)
  2) Doppelklick: Pokedex-Installer.bat
  3) Anweisungen im Fenster folgen
  4) Beim allerersten Mal: am Geraet in Settings 'HID' aus + aus/an

Voraussetzung: Python 3 + Internet (einmaliger Bild-Download).
